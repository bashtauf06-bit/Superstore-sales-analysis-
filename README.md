# Superstore Sales Data Analysis

## 📊 Project Overview
Analyzed 9,800+ sales transactions from a retail superstore dataset using Python to identify sales trends, top products, and regional performance.

## 🛠️ Tools Used
- **Python**: pandas, matplotlib
- **Jupyter Notebook**
- **Data Cleaning**: handled missing values, date parsing

## 📈 Key Insights
1. **West Region dominated** with the highest total sales
2. **Top 3 Products by Revenue**: 
   - Canon imageCLASS 2200 Advanced Copier
   - Lexmark MX611dhe Monochrome Laser Printer  
   - HP Designjet T520 Inkjet Large Format Printer-24
3. **Identified seasonal sales patterns** over time

## 📊 Visualizations
- Line chart: Monthly Sales Trend
- Bar chart: Total Sales by Region

## 🚀 How to Run
1. Download `Sample-Superstore.xls.csv`
2. Open `Superstore_Sales_Analysis.ipynb` in Jupyter
3. Run all cells
